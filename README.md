# Orphelinat l'Espoir du Demain (O.E.D.) — Site Web Officiel

Site web éditorial et immersif de l'**Orphelinat l'Espoir du Demain (O.E.D.)**, centre d'encadrement et d'hébergement dédié aux enfants orphelins et vulnérables à Kinshasa (Commune de Kimbanseke, Route Mokali, Avenue Poto poto 98).

## Stack technique
- **React 19 + TypeScript + Vite**
- **Tailwind CSS v4**
- **GSAP + ScrollTrigger** (sliders verticaux & horizontaux épinglés au scroll, transitions storytelling)
- **Lenis** (défilement fluide)
- **Lucide React** (icônes)

## Installation et lancement local

```bash
npm install
npm run dev
```

## Build de production

```bash
npm run build
npm run preview
```
